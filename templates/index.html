Technical Architecture Brief

1. TF-IDF Content-Based Model

Converts cuisine, features, and location tags into sparse TF-IDF vectors. Computes on-the-fly cosine similarity angles:

sim = cosine_similarity(tfv_matrix[idx], tfv_matrix)

2. Item-Item KNN Collaborative Model

Constructs a sparse User-Restaurant rating matrix across 10,000 ratings. Fits an unsupervised NearestNeighbors model:

knn_model = NearestNeighbors(metric='cosine', algorithm='brute')
